# X40 방 편집 카드

기존 청소 카드와 별도로 쓰는 Home Assistant 지도 편집 화면입니다. 지도 이미지는 원본 그대로 표시하며, 방 번호와 분할선만 겹쳐 그립니다.

## 사용

- **이름 변경:** 방을 선택하고 새 이름을 입력한 뒤 변경 내용을 확인합니다.
- **분할:** 방을 선택하고 지도에서 분할선의 양 끝을 누릅니다. 선이 방의 양쪽 경계를 가로지르는지 확인한 뒤 적용합니다. 확대하면 선을 지정하기 쉽습니다.
- **병합:** 서로 붙어 있는 두 방을 선택하고 확인합니다.
- **기기에 지도 백업:** 현재 저장 지도의 백업을 기기에 요청합니다. 요청 전달과 백업 완료는 다르므로, 완료를 확인한 것으로 표시하지 않습니다.

청소기가 충전대에 있고 진행 중인 작업이 없을 때만 적용할 수 있습니다. 임시 지도, 위치 미확인, 선택 지도 불일치도 차단합니다. 불러온 뒤 지도나 좌표 정보가 바뀌면 다시 불러와야 합니다. 적용 후에는 새 지도를 확인하기 전 같은 요청을 반복할 수 없습니다.

분할·병합은 방 번호와 방별 설정에 영향을 줄 수 있습니다. 먼저 백업하고, 편집 후 방별 예약과 청소 설정을 확인하세요. 백업 복원은 이 카드에 포함하지 않습니다.

## 등록 예시

`x40-room-editor.js`를 모듈 리소스로 등록한 뒤 패널 뷰에 아래 카드를 추가합니다. 기존 청소 화면은 유지합니다.

```yaml
type: custom:x40-room-editor
entity: vacuum.x40_pro_ultra
map_entity: camera.x40_pro_ultra_map
```

청소 카드에 고정 `room_names`가 있으면 기기의 새 이름보다 우선합니다. 편집한 이름을 그대로 표시하려면 이 덮어쓰기 설정을 제거하세요.

## 구현과 검증 범위

지도 카메라의 세 `calibration_points`로 회전·축 반전을 포함한 좌표 변환을 계산합니다. `rooms`의 중심은 선택용 번호 표시이며, 방의 실제 경계 다각형으로 취급하지 않습니다. 지도 경계 분할 결과는 기기에서 결정합니다.

사용하는 작업은 Dreame 통합의 `vacuum_rename_segment`, `vacuum_split_segments`, `vacuum_merge_segments`, `vacuum_backup_map`입니다. 분할·병합·백업에는 현재 선택된 저장 지도 ID를 넘깁니다. 이동·청소 시작·중지 작업은 없습니다.

```sh
node frontend/room-editor/test-room-editor.mjs
```

좌표 변환, 입력 검사, 작업 데이터 생성과 변경 지도 감지를 검사합니다. 실제 지도 캡처를 사용한 브라우저 검사에서는 작업 호출을 가로채 확인·취소, 분할선, 병합 대상, 청소 중 잠금 및 모바일 레이아웃을 확인했습니다. 실제 HA 앱 안의 표시와 기기의 지도 수정·백업 실행은 별도 확인 대상입니다. 통합은 이름 변경을 낙관적으로 표시할 수 있으므로 화면의 새 이름만으로 기기 저장 완료를 단정하지 않습니다.
